# Panduan Dashboard Mitra

> Panduan lengkap Dashboard Mitra Tauthub: mendaftarkan media, menyetujui dan menerbitkan artikel Klien, menyambungkan situs, memantau tautan, dan mencairkan penghasilan. Gunakan peta menu di bawah untuk menemukan halaman panduan yang Anda perlukan.

**Untuk:** Mitra, yaitu pemilik atau pengelola media yang menerbitkan artikel Klien

## Mulai dari sini

- [Mulai cepat untuk Mitra](00-mulai-cepat.md): langkah dari mendaftar sampai penghasilan pertama cair.
- [Mengenal Tauthub](../umum/01-mengenal-tauthub.md): gambaran platform dan perjalanan sebuah artikel.
- [Daftar dan masuk](../umum/02-daftar-dan-masuk.md): membuat akun Mitra dan masuk.
- [Glosarium](../umum/05-glosarium.md): arti istilah yang tampil di layar.

## Peta menu Dashboard Mitra

Menu samping Dashboard Mitra dikelompokkan seperti tabel berikut. Kolom **Panduan** menaut ke penjelasan lengkap menu itu.

| Grup menu | Menu | Fungsi singkat | Panduan |
|---|---|---|---|
| RINGKASAN | **Ringkasan** | Gambaran media, pesanan yang menunggu, penghasilan, dan pesan baru, serta pengenalan tampilan dashboard | [Ringkasan](01-ringkasan.md) |
| RINGKASAN | **VIP Dashboard** | Halaman keanggotaan khusus Mitra VVIP | [VIP Dashboard](02-vip-dashboard.md) |
| MEDIA & PUBLIKASI | **Publikasi** | Meninjau, menyetujui, menolak, dan menerbitkan pesanan artikel | [Publikasi](03-publikasi/README.md) |
| MEDIA & PUBLIKASI | **Daftar Media** | Mendaftarkan dan mengelola media | [Daftar Media](04-daftar-media/README.md) |
| MEDIA & PUBLIKASI | **Link Guardian** | Memantau artikel terbit dan kesehatan domain media | [Link Guardian](05-link-guardian.md) |
| MEDIA & PUBLIKASI | **Akses Crawler** | Kredensial agar pemeriksa Tauthub tidak diblokir firewall | [Akses Crawler](06-akses-crawler.md) |
| PERALATAN | **SEO & Performa** | Memeriksa kualitas domain dan kecepatan situs media | [SEO dan Performa](07-seo-dan-performa.md) |
| REFERRAL | **Referral Mitra** | Tautan pendaftaran dan komisi referral | [Referral Mitra](08-referral-mitra.md) |
| KEUANGAN | **Penghasilan** | Penghasilan, masa tunggu, dan pengajuan penarikan | [Penghasilan](09-penghasilan.md) |
| KEUANGAN | **Invoice** | Arsip penarikan dan status pencairan | [Invoice dan pencairan](10-invoice-dan-pencairan.md) |
| KOMUNIKASI | **Pesan** | Obrolan dengan Klien per artikel | [Pesan](11-pesan.md) |
| KOMUNIKASI | **Dukungan** | Tiket ke tim Tauthub | [Dukungan](12-dukungan.md) |
| PENGATURAN | **Integrasi** | Menyambungkan situs agar artikel terkirim otomatis | [Integrasi](13-integrasi/README.md) |
| PENGATURAN | **Konfigurasi** | Profil, rekening penarikan, notifikasi, dan keamanan | [Profil dan Konfigurasi](14-profil-dan-konfigurasi/README.md) |
| SISTEM | **Apa yang Baru** | Catatan rilis fitur dan perbaikan | [Apa yang Baru](16-apa-yang-baru.md) |

Beberapa fitur tidak punya menu sendiri:

| Fitur | Cara membukanya | Panduan |
|---|---|---|
| Notifikasi dan pengumuman | Klik ikon lonceng di bar atas, lalu **Lihat semua** | [Notifikasi](15-notifikasi.md) |
| Saldo penghasilan | Klik pil saldo di bar atas | [Penghasilan](09-penghasilan.md) |
| Pil tingkat VIP | Klik pil di bar atas (hanya untuk keanggotaan VIP) | [VIP Dashboard](02-vip-dashboard.md) |
| Dashboard Klien | Menu akun di dasar sidebar (hanya untuk Mitra VVIP) | [Akun, peran, dan pindah dashboard](../umum/03-akun-peran-dan-pindah-dashboard.md) |
